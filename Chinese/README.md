##### Console.log {#consolelog}

为了编写我们的第一个 JavaScript 代码，我们使用了一个内置函数 **console.log()**。我们传递一个参数作为输入数据，函数显示输出。我们在 console.log() 函数中传递了 `'Hello, World'` 作为输入数据或参数。

```js
console.log('Hello, World!')
```

##### 带多个参数的 Console.log {#consolelog-with-multiple-arguments}

**`console.log()`** 函数可以接受多个用逗号分隔的参数。语法如下：**`console.log(param1, param2, param3)`**


![console log multiple arguments](../images/console_log_multipl_arguments.png)

```js
console.log('Hello', 'World', '!')
console.log('HAPPY', 'NEW', 'YEAR', 2020)
console.log('Welcome', 'to', 30, 'Days', 'Of', 'JavaScript')
```

从上面的代码片段可以看出，_`console.log()`_ 可以接受多个参数。

恭喜！您使用 _`console.log()`_ 编写了第一个 JavaScript 代码。

##### 注释 {#comments}

我们可以向代码添加注释。注释对于使代码更易读和在我们的代码中留下备注非常重要。JavaScript 不执行我们代码的注释部分。在 JavaScript 中，任何以 // 开头的文本行都是注释，像这样 `//` 括起来的任何内容也是注释。

**示例：单行注释**

```js
// 这是第一个注释  
// 这是第二个注释  
// 我是单行注释
```

**示例：多行注释**

```js
/*
这是多行注释  
 多行注释可以占用多行  
 JavaScript 是网络的语言  
 */
```

##### 语法 {#syntax}

编程语言类似于人类语言。英语或许多其他语言使用单词、短语、句子、复合句等来传达有意义的信息。语法的英语含义是_在语言中创建格式正确的句子的单词和短语的排列_。语法的技术定义是计算机语言中语句的结构。编程语言有语法。JavaScript 是一种编程语言，像其他编程语言一样，它有自己的语法。如果我们不编写 JavaScript 理解的语法，它会引发不同类型的错误。我们稍后 will explore 不同种类的 JavaScript 错误。现在，让我们看看语法错误。

![Error](../images/raising_syntax_error.png)

我故意犯了一个错误。结果，控制台引发语法错误。实际上，语法非常有用。它通知犯了什么类型的错误。通过阅读错误反馈指南，我们可以纠正语法并解决问题。识别和删除程序中错误的过程称为调试。让我们修复错误：

```js
console.log('Hello, World!')
console.log('Hello, World!')
```

到目前为止，我们看到了如何使用 _`console.log()`_ 显示文本。如果我们使用 _`console.log()`_ 打印文本或字符串，文本必须在单引号、双引号或反引号内。
**示例：**

```js
console.log('Hello, World!')
console.log("Hello, World!")
console.log(`Hello, World!`)
```

## 向网页添加 JavaScript {#adding-javascript-to-a-web-page}

JavaScript 可以通过三种不同的方式添加到网页：

- **_内联脚本_**
- **_内部脚本_**
- **_外部脚本_**
- **_多个外部脚本_**

以下部分展示了向网页添加 JavaScript 代码的不同方式。

### 内联脚本 {#inline-script}

在桌面上或任何位置创建一个项目文件夹，将其命名为 30DaysOfJS，并在项目文件夹中创建一个 **_`index.html`_** 文件。然后粘贴以下代码并在浏览器中打开，例如 [Chrome](https://www.google.com/chrome/)。

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>30DaysOfScript:Inline Script</title>
  </head>
  <body>
    <button onclick="alert('Welcome to 30DaysOfJavaScript!')">Click Me</button>
  </body>
</html>
```

现在，您刚刚编写了第一个内联脚本。我们可以使用 _`alert()`_ 内置函数创建弹出警告消息。

### 内部脚本 {#internal-script}

内部脚本可以写在 _`head`_ 或 _`body`_ 中，但最好将其放在 HTML 文档的主体中。
首先，让我们写在页面的头部。

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>30DaysOfScript:Internal Script</title>
    <script>
      console.log('Welcome to 30DaysOfJavaScript')
    </script>
  </head>
  <body></body>
</html>
```

这就是我们大多数时候编写内部脚本的方式。将 JavaScript 代码写在 body 部分是最首选的选项。打开浏览器控制台查看 `console.log()` 的输出。

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>30DaysOfScript:Internal Script</title>
  </head>
  <body>
    <button onclick="alert('Welcome to 30DaysOfJavaScript!');">Click Me</button>
    <script>
      console.log('Welcome to 30DaysOfJavaScript')
    </script>
  </body>
</html>
```

打开浏览器控制台查看 `console.log()` 的输出。

![js code from vscode](../images/js_code_vscode.png)

### 外部脚本 {#external-script}

与内部脚本类似，外部脚本链接可以放在头部或主体中，但最好将其放在主体中。
首先，我们应该创建一个带有 .js 扩展名的外部 JavaScript 文件。所有以 .js 扩展名结尾的文件都是 JavaScript 文件。在项目目录中创建一个名为 introduction.js 的文件，并编写以下代码，并在主体底部链接这个 .js 文件。

```js
console.log('Welcome to 30DaysOfJavaScript')
```

在 _head_ 中的外部脚本：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>30DaysOfJavaScript:External script</title>
    <script src="introduction.js"></script>
  </head>
  <body></body>
</html>
```

在 _body_ 中的外部脚本：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <title>30DaysOfJavaScript:External script</title>
  </head>
  <body>
    <!-- JavaScript external link could be in the header or in the body -->
```

## 数据类型简介 {#introduction-to-data-types}

在 JavaScript 以及其他编程语言中，有不同类型的数据类型。以下是 JavaScript 的基本数据类型：_字符串、数字、布尔值、未定义、空值_ 和 _符号_。

### 数字 {#numbers}

- 整数：整数（负数、零和正数）
  示例：
  ... -3, -2, -1, 0, 1, 2, 3 ...
- 浮点数：小数
  示例：
  ... -3.5, -2.25, -1.0, 0.0, 1.1, 2.2, 3.5 ...

### 字符串 {#strings}

两个单引号、双引号或反引号之间的一个或多个字符的集合。

**示例：**

```js
'a'
'Asabeneh'
"Asabeneh"
'芬兰'
'JavaScript 是一种美丽的编程语言'
'我热爱教学'
'我希望你正在享受第一天'
`我们也可以使用反引号创建字符串`
'字符串可以小到一个字符，也可以大到多页'
'任何在单引号、双引号或反引号下的数据类型都是字符串'
```

### 布尔值 {#booleans}

布尔值要么是 True 要么是 False。任何比较都会返回一个布尔值，即 true 或 false。

布尔数据类型要么是 true 要么是 false 值。

**Example:**

```js
true // if the light is on, the value is true
false // if the light is off, the value is false
```

### Undefined（未定义） {#undefined}

在 JavaScript 中，如果我们不给变量赋值，变量的值就是 undefined。除此之外，如果一个函数没有返回任何值，它也会返回 undefined。

```js
let firstName
console.log(firstName) // undefined, 因为它还没有被赋值
```

### Null（空值） {#null}

Null 在 JavaScript 中意味着一个空值。

```js
let emptyValue = null
```

## 检查数据类型 {#checking-data-types}

要检查某个变量的数据类型，我们使用 **typeof** 运算符。请参见以下示例。

```js
console.log(typeof 'Asabeneh') // string
console.log(typeof 5) // number
console.log(typeof true) // boolean
console.log(typeof null) // object type
console.log(typeof undefined) // undefined
```

## 再次讨论注释 {#comments-again}

记住，JavaScript 中的注释与其他编程语言类似。注释对于使您的代码更易读非常重要。
有两种注释方法：

- _单行注释_
- _多行注释_

```js
// 这是一个单行注释
// let firstName = 'Asabeneh'; 这是一个单行注释
// let lastName = 'Yetayeh'; 这是一个单行注释
```

多行注释：

```js
/*
  let location = 'Helsinki';
  let age = 100;

  This is a Multiple line comment

```

## 变量 {#variables}

变量是数据的 _容器_。变量用于 _存储_ 内存中的数据。当声明一个变量时，会保留一个内存位置。当变量被赋值为一个值（数据）时，内存空间将被填充为该数据。要声明一个变量，我们使用 _var_、_let_ 或 _const_ 关键字。

对于在不同时间变化的变量，我们使用 _let_。如果数据根本不变，我们使用 _const_。例如，PI、国家名称、重力等不会改变，我们可以使用 _const_。在这个挑战中我们不会使用 var，我也不推荐您使用它。它是声明变量的容易出错的方式，有很多漏洞。我们将在其他部分（作用域）详细讨论 var、let 和 const。现在，上述解释已经足够。

有效的 JavaScript 变量名必须遵循以下规则：

- JavaScript 变量名不应以数字开头。
- JavaScript 变量名不允许特殊字符，除了美元符号和下划线。
- JavaScript 变量名遵循驼峰命名法约定。
- JavaScript 变量名在单词之间不应有空格。

以下是有效的 JavaScript 变量示例。

```js
firstName
lastName
country
city
capitalCity
age
isMarried

first_name
last_name
is_married
capital_city

num1
num_1
_num_1
$num1
year2020
year_2020
```

第一个和第二个变量符合驼峰命名法约定。在本材料中，我们将使用驼峰命名法变量（camelWithOneHump）。我们使用驼峰命名法（CamelWithTwoHump）来声明类，我们将在其他部分（类和对象）详细讨论。

无效变量示例：

```js
  first-name
  1_num
  num_#_1
```

让我们用不同的数据类型声明变量。要声明变量，我们需要在变量名前使用 _let_ 或 _const_ 关键字。在变量名之后，我们写一个等号（赋值运算符），然后是一个值（被赋值的数据）。

```js
// Syntax
let nameOfVariable = value
```

nameOfVariable 是存储不同数据值的名称。详见下面的示例。

**声明变量的示例**

```js
// 声明不同数据类型的变量
let firstName = 'Asabeneh' // 人的名字
let lastName = 'Yetayeh' // 人的姓氏
let country = 'Finland' // 国家
let city = 'Helsinki' // 首都城市
let age = 100 // 年龄（岁）
let isMarried = true

console.log(firstName, lastName, country, city, age, isMarried)
```

```sh
Asabeneh Yetayeh Finland Helsinki 100 true
```

```js
// 声明数值变量
let age = 100 // 年龄（岁）
const gravity = 9.81 // 地球重力（m/s²）
const boilingPoint = 100 // 水的沸点，温度（°C）
const PI = 3.14 // 几何常数
console.log(gravity, boilingPoint, PI)
```

```sh
9.81 100 3.14
```

```js
// 变量也可以用逗号分隔在一行中声明，不过我推荐使用单独的行来让代码更易读
let name = 'Asabeneh', job = 'teacher', live = 'Finland'
console.log(name, job, live)
```

```sh
Asabeneh teacher Finland
```
